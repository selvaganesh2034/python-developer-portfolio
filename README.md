## 🌐 இதை Internet-ல் Free-ஆக Publish செய்வது எப்படி? (Free Hosting)

### முறை 1: GitHub Pages (மிகவும் எளிது)
1. GitHub-ல் புதிய repository ஒன்றை உருவாக்கவும் (உதாரணமாக: `my-portfolio`).
2. இந்த folder-ல் உள்ள அனைத்து files (`index.html`, `style.css`, `script.js`)-ஐ upload செய்யவும்.
3. GitHub Repo **Settings** -> **Pages** பகுதிக்கு செல்லவும்.
4. **Branch**: `main` -> **Save** கொடுக்கவும்.
5. 1 நிமிடத்தில் உங்கள் portfolio live link கிடைக்கும் (எ.கா: `https://yourusername.github.io/my-portfolio/`).

### முறை 2: Vercel அல்லது Netlify
- [Vercel](https://vercel.com) அல்லது [Netlify](https://netlify.com)-ல் சென்று இந்த folder-ஐ drag & drop செய்தால் நொடியில் live ஆகிவிடும்!
